Dans l'application, dans un répertoire 'services', crée un service nommé JsonHistoriqueService. Ce service permet de conserver l'état courant d'un objet JSON et l'historique de toutes ses modifications (pattern REDUX). Le service ne conserve pas les états précédents et suivants mais il conserve les modifications demandées. Une modification est un objet. Une classe Modification est la base de tous les types de modifications existant. La classe définit l'action à réaliser sur le JSON. Les membres de la classe fournissent les détails nécessaires. Chaque type de modification a une classe dédiée. Pour chaque classe de modification existe son opposé. Voici les types de modifications à implémenter :
* créer un JSON vide // vider le JSON
* ajouter un noeud de type OBJET (fourni en paramètres ne contenant que des attributs simples) ou TABLEAU VIDE dans un attribut d'un noeud précis du JSON identifié par son chemin
* supprimer un noeud précis du JSON identifié par son chemin
* ajouter un noeud de type OBJET (fourni en paramètres ne contenant que des attributs simples) dans un tableau du JSON identifié par son chemin
* supprimer un noeud présent dans un tableau

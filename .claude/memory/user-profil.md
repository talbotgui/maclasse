Développeur sur le projet "Ma classe" — application SPA Angular 21 destinée aux enseignants du primaire (CP–CM2).

Travaille avec Claude Code comme assistant de développement pour la conception et l'implémentation.

## Préférences techniques

- Angular 21 strict : standalone components, Signals, OnPush, `input()`/`output()`, `inject()`
- Nommage 100% français dans le code (voir [[feedback-02-conventions]])
- SCSS pur avec CSS variables — pas Tailwind, pas de librairie UI externe
- Vitest sans TestBed — instanciation directe des services

## Style de collaboration

- Exige une reformulation et une validation avant toute écriture de code (voir [[feedback-06-collaboration]])
- Sensibilité forte à l'accessibilité RGAA/WCAG AA et à la qualité Sonar
- Préfère les discussions architecturales avant l'implémentation
